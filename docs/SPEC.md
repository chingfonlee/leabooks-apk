# Lea Book TV — 86 吋離線互動觸控繪本系統規格書

## 1. 專案目標與執行環境

* **目標裝置**：PERSONA 盛源 KTA-PRO-FULL 系列 86 吋多點觸控螢幕（內建電子白板，Android 14，橫向 16:9）
* **網路條件**：**完全離線**（現場無網路連線）
* **安裝方式**：Android APK 側載安裝（不啟用 Kiosk 鎖定，允許正常返回系統桌面）
* **語言版本**：繁體中文（`zh`）為主（資料結構保留多語擴充欄位）

---

## 2. 整體架構（做法 2：輕量 APK ＋ 本機影片資料夾）

* **技術棧**：**Vite + React + TypeScript + Capacitor** 打包為 Android APK。
* **雙模式整合於單一 App**：
  1. **繪本閱讀（All-in-APK 內建）**
     * 11 本繪本的 WebP 插圖（`1600×777`，每本 18 頁）、中文字幕資料與背景音樂（`music.mp3`）直接打包在 APK 內，安裝即用。
     * 預設去重共用 `music.mp3`（APK 總體積約 25 MB 左右），同時在資料模型保留每本書獨立的 `musicSrc` 欄位，方便日後為個別繪本替換專屬音樂。
     * 提供自動化匯入腳本（`npm run import:books`），唯讀同步 `C:\Users\user\claudecode\LeaQRbook` 的書籍資料與素材；未來新增繪本時重跑匯入並打包新版 APK 覆蓋安裝即可。
  2. **繪本影片（讀取本機資料夾）**
     * 影片不打包進 APK，避免 APK 膨脹至數 GB 造成安裝失敗與更新困難。
     * 透過自建 Android 14 原生 Capacitor Plugin（使用 Storage Access Framework `ACTION_OPEN_DOCUMENT_TREE` + 持久化權限），讓管理人員於首次部署時指定白板本機影片資料夾（例如 `Movies/LeaBookVideos` 或外接儲存裝置）。
     * App 透過本機 `127.0.0.1` HTTP Range 串流服務直接讀取 `content://` 影片檔，支援大檔播放與拖曳進度條，完全離線且不佔用額外記憶體。
     * 影片清單自動掃描資料夾內的 `.mp4` / `.webm` 檔案，並**自動依檔名配對**繪本封面與中文書名（支援 `六歲的生日蛋糕.mp4`、`01-六歲的生日蛋糕.mp4`、`the-sixth-birthday-cake.mp4` 等命名；未配對到的新影片亦自動列出並以檔名作為標題，不需手動設定）。

## 3. 介面與互動設計（86 吋大螢幕觸控最佳化）

### 3.1 首頁：大圖書牆（Grid 書架）
* 頂部導覽列提供明確大按鈕切換：
  * **「繪本閱讀」**（顯示 11 本繪本大封面卡片牆，橫向 4 欄排版，觸控目標大）
  * **「繪本影片」**（顯示本機資料夾掃描到的影片卡片牆，右上角提供「選擇／重新掃描影片資料夾」按鈕）
  * **「自動輪播」**入口：可快速選擇「指定單本自動播放」或「勾選多本連續輪播」。
* 每張繪本卡片點擊後提供直覺進入方式（直接開啟閱讀，並可一鍵切換自動播放）。

### 3.2 繪本閱讀頁：電影劇場式分段字幕（選項 B）
* **大圖為主**：`1600×777` 寬幅插圖置中放大顯示，盡量填滿 86 吋畫面，背景採溫潤深色劇院底色。
* **底部電影字幕條**：
  * 畫面底部以柔和深色漸層疊加 **2～3 行超大繁體中文字幕**（針對 2～4 公尺觀看距離設計字級與行距）。
  * **自動分段演算法**：由於每頁文字量介於 0～487 字（平均約 163 字），系統依中文句號／問號／驚嘆號／換行自動切分為多段字幕。
  * 在自動播放的 **15 秒／頁** 時間內，依各段字數比例自動分配停留秒數，像電影字幕一樣平順切換顯示（字幕條下方附帶細微段落指示點）。
  * 字幕**常駐顯示（不提供字幕開關）**，保持大螢幕介面簡潔。
  * 手動模式下，使用者除翻頁外，也可點按字幕區快速切換上／下一段字幕。

### 3.3 互動邏輯：觸控 ＋ 15 秒自動播放共存（模式 2）
* **觸控翻頁**：
  * 支援**左右滑動（Swipe）**與**點擊螢幕左／右側區域**翻頁，附帶柔和過場動畫。
* **自動播放（每頁 15 秒）**：
  * 畫面底部顯示細長 **15 秒倒數進度條**。
  * 支援「單本循環播放」或「依序自動接續下一本繪本」。
* **人機共存與自動恢復**：
  * 自動播放進行中，只要有觀眾觸控螢幕（滑動翻頁、點按字幕或控制列），即自動暫停自動翻頁並切換為**手動閱讀模式**。
  * 若畫面閒置超過 **60 秒**（可於設定調整）無人觸控，系統自動恢復原本的 15 秒自動輪播模式。

### 3.4 音訊管理
* 進入繪本閱讀頁自動播放該書對應的 `music.mp3`（循環播放），介面提供大型觸控靜音／音量按鈕。
* 切換至「繪本影片」播放時，自動暫停背景音樂，確保影片原音不互相干擾。

## 4. 預計專案目錄結構

```text
lea-book-TV/
├── docs/
│   ├── leaqrbook-reference.md   # LeaQRbook 來源參考摘要
│   └── SPEC.md                  # 本規格書
├── scripts/
│   ├── import-books.mjs         # 從 LeaQRbook 唯讀匯入書籍資料與去重音樂
│   └── build-apk.ps1            # 一鍵建置前端 + 同步 Capacitor + 打包 Android APK
├── src/
│   ├── components/              # 書牆、劇場閱讀器、分段字幕、影片播放器、輪播設定
│   ├── data/                    # 匯入生成的 books.json 型別與載入器
│   ├── plugins/                 # LocalVideoLibrary TS 介面（含瀏覽器開發模擬）
│   └── utils/                   # 中文字幕智慧分段演算法、閒置偵測 Hook
├── public/books/                # 匯入腳本產生的 WebP 與 MP3（不直接手改）
├── android/                     # Capacitor Android 專案（含 LocalVideoLibrary 原生外掛）
└── release/                     # 建置產出的可安裝 APK
```

## 5. 開發與驗證里程碑

1. **階段一：專案初始化與書籍匯入** — 建立 Vite + React + TypeScript 專案，撰寫 `import-books.mjs` 匯入 11 本中文繪本與去重 `music.mp3`。
2. **階段二：繪本大圖書牆與劇場式閱讀器** — 實作 4 欄大圖書牆、電影式分段字幕、15 秒自動翻頁進度條、觸控暫停＋60 秒閒置恢復、背景音樂播放、指定單本／多本輪播。
3. **階段三：本機影片資料夾播放功能** — 實作「繪本影片」頁籤與 Android 14 SAF 原生外掛（`LocalVideoLibrary` + 本機 HTTP Range 串流），並附桌面瀏覽器測試模式。
4. **階段四：Capacitor 封裝與 APK 建置驗證** — 整合 Android 專案、確認本機 Gradle 編譯產出可安裝 APK，並提供 86 吋白板安裝與影片資料夾設定說明書。
